# Ядро R3

Контракт r3/1: R3-CONTRACT.md. `core/game-core-r3.ts` и `core/content-r3.ts` — новое детерминированное ядро и151 типизированная content entity. Старые game-core/content R1/R2 и их архивы остаются побайтно неизменными. R3 pins: r3-core-1/r3-content-1/r3-meta-1/save4/API1.

Партия содержит15волн, командиров5/10/15, пять героев, три семейства зданий и шесть обычных ролей. Лекарь лечит союзников; бронированный враг снижает урон; скрытый диверсант идёт по отдельному маршруту и становится доступным целью только при действующем обнаружении. Командиры выполняют осаду, обход и магическое усиление.

`send_expedition` принимается в подготовке, только для доступного героя. Один герой отсутствует; anchor зарезервирован, атаки/каст/телепорт отключены. Лагерь300 боевых тактов даёт160золота; лавка600 сохраняет выбор предмета; Рошан900 даёт отдельный bound Aegis. Pause/preparation не двигают таймер. В save4 остаются nullable expedition, два ordered item slots, aegisToken и pendingRewards.

`equip_item` — оплаченная явная замена; `choose_reward` — бесплатная явная замена bound hero; `discard_reward` — явный отказ. UI preview/cancel не отправляют команду. Все проверки предшествуют gold/state mutation. Pending choice блокирует start_wave и не может сосуществовать с новой вылазкой. Четыре известные behavior: дополнительная цель, сокращение периода атаки, обнаружение, лечение. Уникальность по behavior, bounds/compatibility — из content. Неизвестные refs/handlers/config отвергаются.

Aegis автоматически погашается только при гибели своего героя, возвращает полный maxHP в той же стадии смерти и действует один раз. Это отдельный token, не item slot. Последующая гибель использует обычные правила.

Ядро принимает команды со sequence/id/tick и выдаёт durable события; renderer не управляет симуляцией. Детализация clock/стадий наследует R2; результаты сверяются на разных размерах advanceTicks. Авторская стратегия прошла15волн: seed0x12345678,30515тактов,258команд,трон240HP. Независимая: seed6996017,37890тактов,72команды,трон79HP. Это воспроизводимые прогоны, не подтверждение общего баланса или удовольствия.

Тесты: core-r3-rules.test.mjs, core-r3-party-proof.test.mjs, qa-r3-core.test.mjs. Команды в TEST-REPORT-R3.md. Финальный UI/API/VPS имеют отдельные границы приёмки.
