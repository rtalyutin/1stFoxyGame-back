# Состав Last-Throne-R2.zip

Корневой каталог архива: Last-Throne-R2/. Готовая версия: releases/r2-001; исходники соответствуют sourceHash этой версии. Подробные проверки: TEST-REPORT-R2.md и QA-R2.md.

Включены исходники фронта, ядра, API, БД и доставки, закреплённый package-lock.json, тесты и их evidence, ТЗ v0.5, инструкции README.md и ops/RUNBOOK-R2.md. Exact releases/r0-002 и r1-002 сохранены рядом с r2-001. Готовые releases содержат production-зависимости.

Dev node_modules, локальные базы, временные caches, внешний Chromium и r2-preview-001 не включены. Для разработки выполнить npm ci на Node24; готовые releases не пересобирать под тем же ID. Новая сборка должна иметь новый releaseId.

Поставка подготовлена локально. Установка на сервере первой игры не выполнялась. Переход уже установленного runtime R0/R1 на runtime R2 — отдельное плановое обновление; обычные совместимые обновления после этого выполняются через стабильный gateway и A/B API, согласно runbook.
