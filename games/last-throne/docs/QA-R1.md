4 октября 2026. Проверял отдельный QA-исполнитель, не автор ядра, API, БД, renderer или HUD. Реализация не изменялась проверяющим; добавлены независимые сценарии и отчёт.

**Локальный функциональный объём R1: PASS.** Открытых подтверждённых дефектов в проверенной области итоговой сборки нет. Это не приёмка VPS, производительности целевого компьютера, баланса или понятности игры людям.

`evidence_status: VERIFIED` · `gate_verdict: PASS` для перечисленных ниже локальных свойств. Непроверенные серверные и пользовательские gate остаются `BLOCKED/NOT_TESTED`. `next_action`: передать эту конкретную локальную поставку пользователю; серверные проверки проводить отдельно при наличии доступа. `return_to`: владелец реализации.

Исходный отчёт с этой ошибкой наблюдения сохранён как [visibility-observation-failure.json](../evidence/qa-r1/browser/visibility-observation-failure.json). Этот прогон целиком зелёным не объявляется. Зависимая проверка заменена измерением фактического первого rAF и повторена **отдельно на том же неизменённом r1-002**; её результат PASS приведён выше. Предыдущие19 пройденных свойств не затронуты изменением oracle. Поставляемый основной harness также исправлен на измерение кадра, а не фиксированную паузу200мс.

В полной партии только ожидание завершения волн использовало непрерывные virtual `performance.now`/rAF с коэффициентом8; взаимодействия, renderer и API оставались настоящими, core выполнял фиксированные такты. Это функциональная проверка пяти волн, **не измерение real-time FPS**. Отдельные focus/teleport и visibility-пробы использовали обычные часы без ускорения. Состояние игры читалось через diagnostics/IndexedDB/API; скрытых команд или мутаций игровых объектов не было.

## Пределы вывода

Не проверены целевой VPS и первая игра до/после установки, Docker/Nginx/TLS/container identity, production Unix socket, backup/restore, независимые PostgreSQL-сессии и серверная ёмкость. Локальные delivery HTTP-фикстуры не подтверждают эти свойства сервера.

Не подтверждены физический GPU, согласованный FPS/latency бюджет, другие браузеры/телефоны, реальное OS freeze/discard, спонтанный GPU failure, пользовательский баланс и протокол понятности с людьми. Контролируемый `document.hidden` event проверяет адаптер приложения; он не равен настоящему скрытию вкладки ОС. Подъём графики после контролируемой потери WebGL не доказывает восстановление при любом аппаратном отказе.

Проверены browser victory/terminal/no-Continue, API terminal/idempotency и модель pending checkpoint→offline finish. Полный browser-сценарий **поражение с pending checkpoint при отсутствии сети** отдельно не разыгрывался; эта граница покрыта автоматическими API/SaveManager-сценариями, не заявлена отдельным e2e PASS. GLB в поставке отсутствуют. Узнаваемость/эмоциональное восприятие магии не выводятся из screenshots и согласия агента.

Адресно просмотрены header и §10.1 ТЗv0.4: существенной некорректности заявленных границ локальной поставки не найдено. Проверка не распространялась на весь будущий план R2–R4.
